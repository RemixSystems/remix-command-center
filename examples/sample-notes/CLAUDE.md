# CLAUDE.md

This folder is the notes system for a one-person design studio. Read [[Home]] first.

- `00-Inbox/` holds quick captures. Sort them weekly.
- `10-Projects/` holds one note per client project, listed in [[Projects]].
- `20-People/` holds one note per person, listed in [[People]].
- `30-Areas/` holds ongoing responsibilities.
- `Daily/` holds one note per day.

Answer in short paragraphs. Draft emails, never send them.
